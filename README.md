# 🚗 Extração de Quilometragem (KM)

Script Python para extração automática de dados de quilometragem de veículos a partir de sistemas legados ou planilhas.

![Python](https://img.shields.io/badge/Script-Python-blue)
![Automation](https://img.shields.io/badge/Task-Automation-green)

## 📌 Funcionalidades

*   Processamento de dados via Pandas.
*   Automação de leitura de entradas.
*   Geração de relatórios de saída.

## 🚀 Como Usar

1.  Ative o ambiente virtual:
    ```bash
    .\venv\Scripts\activate
    ```
2.  Execute o script principal:
    ```bash
    python Info.py
    ```

## 🛠️ Requisitos

*   Python 3.x
*   Bibliotecas listadas no ambiente virtual.
